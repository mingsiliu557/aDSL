# Current 33-case physical comparison

See [report](report.md), [main table](main_table.csv), and [paired case table](comparison_33.csv).
This public export preserves the numeric results and all 132 connectivity/support24
JSON evidence files at the paths recorded in verification.json. Their file hashes
are unchanged. Source/asset hashes identify the frozen outputs; raw generated
assets, credentials, server paths, invocation logs and local runner files are not
part of this export. The geometry inputs are required to independently remeasure.

All 33 cases remain in the table. Nine Ours connectivity measurements are unavailable
because material intersection returned an invalid volume. They are unsuccessful
in the fixed denominator, not observations of interpart disconnection. NSV24 and N
use all 33 jointly measurable cases. Generation model conditions differ; this is
a comparison of existing outputs, not a model-controlled causal experiment.
